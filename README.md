# 善意同行

一个面向校园日常小需求的互助平台。比赛版本聚焦学习互助、物品借用，以及发布、响应、协作、完成、感谢的完整流程。

当前处于开发阶段。此前策划书描述长期设计，本次实现范围以本文档和实际代码为准。

## 本地运行

需要 Node.js 24 或更高版本。在项目文件夹打开终端，运行：

```sh
npm start
```

在浏览器打开 http://127.0.0.1:3000 。项目使用 Node.js 内置功能，不需要额外安装依赖或数据库。
