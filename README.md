# 校园岛

讲道题，借件东西，找人搭把手。

把校园里的求助放在一起，方便有需要的人，也方便能帮忙的人。比赛版本聚焦学习交流和物品借用，完成发布、回应、确定帮助者、私信、确认完成和感谢的闭环。

**在线体验：[打开校园岛](https://campus-kindness-cjq.round-bell-5229.chatgpt.site)**

可创建独立身份，也可使用三个共用演示身份。目前学校圈均为演示圈，**真实学校邮箱认证待配置**，选择学校不代表认证通过。请只填写模拟内容。预设身份、初始求助与带“示例”标记的完成案例不代表真实运营成绩。

七校固定为：武汉大学、华中科技大学、中国地质大学（武汉）、武汉理工大学、华中农业大学、华中师范大学、中南财经政法大学。

## 项目特点

- 确定帮助者后再行动，避免多人重复处理。
- 借用与归还分步确认，不因借用者单方点击就认定出借者已收到。
- 独立身份拥有自己的记录，感谢留给具体的人，不设置善良程度排行榜。
- 本机运行使用 Node.js 内置模块，无第三方运行依赖，不需另装数据库。

## 运行教程

需要 **Node.js 24 或以上**，以及支持 HTML dialog 的较新 Edge、Chrome、Firefox 或 Safari。

Windows 下载完整项目后双击 **启动校园岛.cmd**，浏览器自动打开 <http://127.0.0.1:3000>。保留启动窗口，关闭窗口或 Ctrl+C 停止服务。旧名称启动脚本保留为兼容入口。

命令行方式：

```sh
git clone <你提交的 GitHub 仓库地址>
cd <项目文件夹>
npm start
```

本机无需 npm install。3000 端口占用时关闭旧服务，或设置其他 PORT。

手机直接访问上方在线体验地址即可，不需项目电脑开机。本地预览可双击 **手机访问校园岛.cmd**，手机与电脑连接同一 Wi-Fi，输入启动窗口显示的完整地址和端口。电脑需保持运行并允许专用网络访问；蜂窝网络不能直接访问电脑的局域网地址。

## 创建身份与保存记录

1. “切换身份”→“创建身份”，填写昵称并选头像。
2. 保存**只展示一次的恢复口令**。跨设备、清理浏览器或退出后，通过“恢复身份”继续使用；丢失恢复口令暂不能找回。
3. 在个人主页搜索学校，加入对应**演示圈**。真实邮箱认证显示待配置，不会生成真实认证标记。
4. 新身份的求助、参与、感谢与消息从空记录开始。独立身份会话最长保留 30 天，同设备可切换已保存身份。

恢复口令相当于演示账号的登录凭据，请勿分享。后端仅保存其哈希，不把恢复口令写入普通资料或仓库。

预设三个身份由所有访客共用，切换到相同演示身份的人可以看到该身份的记录和私信。需要独立记录时请创建自己的身份。游客默认浏览华中师范大学演示圈；独立身份尚未选择学校时不能浏览学校圈、发布或回应。

本机数据保存在忽略提交的 data/store.json、data/uploads/，重启保留。云端使用独立 D1 数据库和私有 R2 图片存储，本机数据不会上传。代码升级增量兼容已有记录，不清空求助、私信或感谢。

## 完整示例

### 学习交流

1. 浏览器 A 创建身份，加入某学校演示圈，发布“想请人讲一道 C++ 题”，选择线上；说明可留空。
2. 另一浏览器或无痕窗口 B 创建另一身份，加入**同校演示圈**，找到求助并点“我能帮”。
3. A 进入详情“确定帮忙”。双方到“消息”发送文字或题目图片，点击摘要返回求助详情。
4. B 申请完成，A 确认完成。会话保留只读历史，A 点“说声谢谢”。双方在发出的/收到的页面看到感谢。
5. 重新打开或用恢复口令恢复身份，检查自己的历史和阅读状态。

### 物品借用

1. A 发布“想借一把螺丝刀”，填写公共交接地点、回应截止、预计归还时间。
2. B 回应，A 选定 B，B 交付后点击“已交付”。
3. A 点击“已归还”。系统提醒 B“对方已提交归还，请确认收到”，此时尚未认定归还完成。
4. B 确认收到后申请完成，A 确认完成并发送感谢。

可使用预设身份快速体验；首页明确标识的案例展示进行中和已完成流程，不混入新身份的个人记录。

## 限制与待配置

- 私信图片一次一张，PNG/JPEG/WebP，最多 3 MB；后端校验文件特征，通过参与者权限接口读取。
- 独立身份的会话、图片和私有感谢仅授权参与者可看；跨学校直接访问也在后端拦截。
- 打开网站期间每 15 秒检查消息；离线消息保存，下次进入可读。尚无关闭网站后的系统推送。
- **真实学校邮箱认证待配置**（按用户本轮决定）。邮箱服务、各校域名及无邮箱替代方式尚未确定；学校选择不是在读证明。
- 学校变更与历史记录迁移方案待定，目前不允许自行更换学校。
- 深色模式、分享预览、首次引导、语音视频、站外推送暂缓。
- 比赛规模存储：云端单状态快照约 1.8 MB 上限，每 IP 五分钟最多 120 次写入。尚无正式运营审核、自动备份和账号找回体系。

## 验证

```sh
npm test
```

15 项测试覆盖学习/借用闭环、权限、持久化、示例增量迁移、真实 SQLite 云端适配与并发重试、独立身份恢复、七校隔离、通知去重、图片访问、未读保存及归还双向确认。

Edge 浏览器另验证两独立身份从创建到感谢、图片预览、键盘操作、搜索空状态及 360/390/640/768/1024/1440 像素布局。原生 Worker 本地预览验证了 D1 身份、私信、已读保存及 R2 私有图片。

## 工程与设计依据

| 路径 | 用途 |
| --- | --- |
| public/ | 页面、样式、身份与消息交互、用户提供的品牌图片 |
