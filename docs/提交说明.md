## 可复制的项目内容

项目名称：校园岛

项目简介：校园岛是一款面向校园日常求助的轻量互助平台，聚焦学习交流与物品借用。用户可以发布求助、回应需求并确定帮助者，通过文字和图片私信沟通，完成后确认结果并发送感谢。平台支持独立身份、个人主页、七校演示互助圈、系统进度通知和未读消息留存，形成从求助到感谢的完整闭环。

项目亮点：

1. 确定帮助者后开启关联求助的两人私信，减少重复行动。
2. 借用物品采用交付、提交归还、确认收到的双向确认流程。
3. 独立身份拥有各自的求助、参与、感谢与消息，学校圈访问范围由后端校验。
4. 本地和云端共享业务规则，刷新与重启保留数据，支持手机与桌面访问。

技术实现：Node.js 24、原生 JavaScript/HTML/CSS、本地文件持久化；在线版使用 Cloudflare Workers、D1、R2。测试覆盖权限、状态流转、持久化和并发更新。

当前边界：学校圈为演示模式，真实学校邮箱认证待配置；三个快捷演示身份由访客共用。独立身份的记录分别保存。未实现站外推送、学校变更、正式运营审核及账号找回。

## 推荐三分钟演示

1. 打开互助角，展示搜索、分类、待回应/进行中/已完成状态和手机界面。
2. 用两个浏览器环境创建两个身份，加入同一演示学校圈。创建时保存恢复口令，勿展示给评审以外的人。
3. A 发布学习求助，B 回应，A 确定 B；展示消息通知、文字与图片私信。
4. B 申请完成，A 确认并发送感谢；展示双方各自的互助与感谢记录。
5. 说明借用流程必须由出借方确认收到，展示归还状态与完成案例。
6. 如时间不足，使用预设演示身份和带标记的流程案例，不把示例描述为真实运营数据。

## 评审运行

安装 Node.js 24 或以上，下载整个仓库后双击“启动校园岛.cmd”，或者在项目目录运行 npm start，访问 http://127.0.0.1:3000。

本机运行不需 npm install 或额外数据库。测试为 npm test。详细操作示例见根目录 README。
